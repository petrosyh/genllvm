# GenLLVM

Randomized testing of LLVM IR Code based on the [Vellvm](https://vellvm.github.io/vellvm/) project.

# Build

This project takes Vellvm as a git submodule, so clone the repository using the `--recurse-submodules` flag:


```
git clone --recurse-submodules https://github.com/vellvm/genllvm.git
```
